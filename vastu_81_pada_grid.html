81 पद वास्तु शक्ति चक्र

Apne ghar ka map upload karein, plot ki boundary trace karein, North wall set karein — 81-pada Devata grid overlay ho jayega

1Ghar ka Map / Plan Upload Karein

Photo, scanned drawing ya floor plan — koi bhi image chalegi.

2Plot ki Boundary Trace Karein

Apne plot ke saare corners par tap/click karein — 4 ho ya usse zyada (L-shape ya koi bhi irregular plot bhi chalega). Order mein, boundary ke around ghoomte hue click karein. Khatam hone par "Boundary Complete" dabayein.

Corners: 0

3North Wall Chunein

Jo wall (deewar) North ki taraf hai, uske dono corners (dono end-points) par click karein. Isse wall ki exact direction ke hisaab se grid seedha (bina tirछा) align hoga.

Abhi North wall set nahi ki gayi.

4Shakti Chakra (81 Pada)

Outer 32 Devata Brahmasthan (9 pada) Inner Devata (arms + corner padas)
Hara outline aapke asli plot ki boundary hai. 81-pada grid us plot ko North-South ke hisaab se sabse chhote complete rectangle mein fit karke banaya gaya hai — jo pada is hare outline se bahar hain, wo "extension" hain; jo area grid ke bahar hai lekin plot ke andar tha, wo "cut" hai. Agar aapka plot pehle se hi rectangle hai, to hara outline grid ke corners se hi match karega.
